# Техническое задание на проект "Демонстрационный стенд модуля pathlib"

## 1. Общая информация
**Название проекта:** Демонстрационный стенд модуля pathlib  
**Заказчик:** Учебная организация HERNY  
**Исполнитель:** Группа HERNY  
**Цель проекта:** Создать консольное приложение для наглядной демонстрации возможностей модуля `pathlib` стандартной библиотеки Python.

## 2. Описание задачи (что нужно сделать)
Необходимо разработать модульное консольное приложение, которое в интерактивном режиме демонстрирует практическое применение ключевых инструментов модуля `pathlib`. Приложение должно показывать преимущества объектно-ориентированного подхода к работе с путями по сравнению с модулем `os.path`.

## 3. Функциональные требования (что система должна уметь)
1. Система должна предоставлять текстовое меню для выбора демонстрации.
2. Система должна демонстрировать создание и навигацию по путям через `Path`.
3. Система должна показывать разбор компонентов пути (`name`, `stem`, `suffix`, `parent`, `parts`).
4. Система должна демонстрировать композицию путей с оператором `/`.
5. Система должна показывать работу с файлами (чтение, запись, переименование).
6. Система должна демонстрировать работу с директориями (`mkdir`, `iterdir`, `rmdir`).
7. Система должна показывать поиск файлов через `glob()` и `rglob()`.
8. Система должна демонстрировать практическую утилиту `ProjectManager` для анализа проекта.
9. Система должна корректно обрабатывать неверный ввод пользователя.

## 4. Нефункциональные требования (ограничения)
1. Язык программирования: Python 3.8+
2. Используемые библиотеки: только стандартная библиотека Python
3. Интерфейс: консольный (CLI)
4. Архитектура: модульная (разделение на examples, project_manager, test)
5. Код должен соответствовать PEP 8
6. Проект должен запускаться на Windows, Linux и macOS

## 5. Требования к интерфейсу
1. При запуске программы отображается главное меню с нумерованными пунктами.
2. Меню содержит следующие пункты:

4. После выполнения демонстрации программа возвращается в главное меню.

## Описание модулей

### 1. `examples.py` - Примеры использования
Содержит 10 функций-демонстраций возможностей `pathlib`:

- **`example_path_creation()`** - создание абсолютных, относительных путей, `Path.cwd()`, `Path.home()`
- **`example_path_components()`** - разбор `name`, `stem`, `suffix`, `parent`, `parts`, `root`, `drive`
- **`example_path_composition()`** - композиция через оператор `/`, `with_suffix()`, `with_name()`
- **`example_path_checks()`** - проверка `exists()`, `is_file()`, `is_dir()`, `is_symlink()`, `is_absolute()`
- **`example_file_operations()`** - `write_text()`, `read_text()`, `read_bytes()`, `stat()`, `rename()`
- **`example_directory_operations()`** - `mkdir()`, `iterdir()`, `rmdir()` с вложенными структурами
- **`example_glob_search()`** - поиск через `glob()` и `rglob()` по паттернам
- **`example_filtering()`** - фильтрация файлов по расширению и размеру, сортировка
- **`example_copy_move()`** - копирование и перемещение файлов и директорий
- **`example_name_manipulation()`** - `with_suffix()`, `with_name()`, `with_stem()`

### 2. `project_manager.py` - Практическая утилита
Содержит класс `ProjectManager` для управления структурой проекта:

- **`scan_project(max_depth)`** - сканирование проекта и сбор статистики
- **`find_files(pattern, file_type)`** - поиск файлов по паттерну или типу
- **`get_project_tree(max_depth)`** - генерация текстового дерева проекта
- **`copy_files(pattern, dest_dir)`** - копирование файлов по паттерну
- **`delete_files(pattern, confirm)`** - удаление файлов с подтверждением
- **`generate_report(output_file)`** - генерация отчёта о проекте
- **`export_to_json(output_file)`** - экспорт статистики в JSON

### 3. `test_project_manager.py` - Тесты
Содержит юнит-тесты для `ProjectManager`:

- **`TestProjectManager`** - тесты основных методов (сканирование, поиск, копирование, удаление, отчёт, JSON-экспорт)
- **`TestPathLibIntegration`** - интеграционные тесты с pathlib (композиция путей, операции, glob, директории)

### 4. `docs/` - Документация
- `overview.md` - инженерное описание инструмента pathlib
- `task.md` - техническое задание на практику
- `conclusions.md` - выводы и рефлексия
- `sources.md` - использованные источники

## Демонстрации

### 1. Создание и навигация по путям
Демонстрирует создание путей через `Path()` — абсолютных, относительных, а также получение текущей и домашней директории через `Path.cwd()` и `Path.home()`.

### 2. Компоненты пути
Показывает разбор пути на компоненты: `name`, `stem`, `suffix`, `parent`, `parts`, `root`, `drive`.

### 3. Композиция путей
Демонстрирует построение путей с помощью оператора `/`, а также замену расширения и имени через `with_suffix()` и `with_name()`.

### 4. Проверка типов и существования
Показывает проверки `exists()`, `is_file()`, `is_dir()`, `is_symlink()`, `is_absolute()` на реальных файлах.

### 5. Работа с файлами
Демонстрирует создание, чтение, запись, получение метаданных (`stat()`) и переименование файлов.

### 6. Работа с директориями
Показывает создание вложенных директорий (`mkdir(parents=True)`), итерацию (`iterdir()`) и удаление.

### 7. Поиск файлов (glob)
Демонстрирует поиск через `glob()` (не рекурсивно) и `rglob()` (рекурсивно) с различными паттернами.

### 8. Фильтрация и обработка файлов
Показывает фильтрацию файлов по расширению, размеру и сортировку через list comprehension.

### 9. Копирование и перемещение
Демонстрирует копирование файлов и директорий через `shutil.copy()`, `shutil.copytree()` и перемещение через `rename()`.

### 10. Работа с расширениями и именами
Показывает `with_suffix()`, `with_name()`, `with_stem()` для манипуляции именами файлов.

## Ключевые концепции

### 1. Объектно-ориентированные пути (Path)
- **Проблема:** строковые пути через `os.path` неудобны и подвержены ошибкам
- **Решение:** объекты `Path` инкапсулируют логику работы с путями
- **Пример:** `Path('/home/user') / 'documents' / 'file.txt'`

### 2. Композиция путей (оператор /)
- **Проблема:** конкатенация строк для построения путей ненадёжна
- **Решение:** оператор `/` для интуитивного построения путей
- **Пример:** `base / 'subdir' / 'file.txt'`

### 3. Чтение и запись файлов
- **Проблема:** необходимость использования `open()` с контекстным менеджером для простых операций
- **Решение:** методы `read_text()`, `write_text()`, `read_bytes()`, `write_bytes()`
- **Пример:** `Path('file.txt').write_text('Hello')`

### 4. Поиск файлов (glob/rglob)
- **Проблема:** модуль `glob` работает со строками и не интегрирован с путями
- **Решение:** методы `glob()` и `rglob()` как часть объекта `Path`
- **Пример:** `Path('.').rglob('*.py')` — рекурсивный поиск Python-файлов

### 5. Проверка и метаданные
- **Проблема:** разрозненные функции `os.path.exists()`, `os.path.isfile()` и т.д.
- **Решение:** методы объекта `Path`: `exists()`, `is_file()`, `is_dir()`, `stat()`
- **Пример:** `Path('file.txt').exists()` — проверка существования
